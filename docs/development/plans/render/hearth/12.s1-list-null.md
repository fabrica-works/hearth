### 12.s1 A null inside a list refused in a document
Scope: the document half above; a `task.json` is unchanged.
Needs: 12.2.
Files: config `src/error.rs` (`Shape::ListNull`), `src/document.rs`,
`src/tests/document.rs`; render `src/errors.rs` (`Decode::ListNull`);
records `src/errors.rs` (`Decode::ListNull`: message `null inside a
list` beside `:202`, code `list_null` beside `:261`); builder
`src/translate/errors.rs` (beside `:44` and `:106`),
`src/tests/translate/errors.rs` (beside `:26`, and a row beside
`:130-132`).
Shape: `document` refuses, before its field loop (`:37`), a value that
holds a `null` at any depth below a list, with `shape(at,
Shape::ListNull)` at the first such `null` in document order. The walk
keeps an explicit stack of the lists and maps still to read, grown by
doubling as `place` grows a list (`json.rs:282-288`); no recursion, and
its one `while` is bounded by the value's nodes, which the decoder's
limits bound: the report quotes `rg -n '\b(loop|while)\b'` with that
reason. A `null` outside a list keeps its meaning (12.1: it removes).
Test shape: in config `src/tests/document.rs`, under 20 ms:
`a_null_inside_a_list_is_refused_at_the_null`, a `const` table of two
rows, `[1, null]` and `[{"a": null}]` as a task's setting value, each
with its literal line and column; the builder's translation table gains
`ListNull`'s row.
Proof: focused, those two tests once; then hearth's gate through `land`.
Don't: change the decoder (`json.rs`), a `task.json`'s path
(`As::Declaration`, builder `read.rs:53`), or another fault's message or
code.
